## What it does

- Finds tests by scanning source, then confirms them with each runner's own listing.
- Runs the whole workspace, one file, the test nearest the cursor, the selected row, or the tests that failed last time.
- Shows status, duration, location, message, and stack trace for each test, and keeps the full runner output.
- Marks test lines in the gutter and puts failure messages beside them.
- Collects coverage and shows it in the gutter, on the scrollbar, and in the file explorer.
- Runs tests on save when watch is on.
- Imports JUnit and Cobertura files from other tools.
- Accepts adapters from other plugins for more ecosystems.
