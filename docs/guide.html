Guide

Test Observatory requires Fresh 0.4.10 or newer. Open Package: Install from URL and enter https://github.com/willibrandon/fresh-test-observatory. Then run Test Observatory: Open from the command palette.

Supported workflows

Rust uses cargo-nextest when available and falls back to Cargo. Coverage uses cargo-llvm-cov. Go uses the standard go test -json stream and native cover profiles. .NET understands VSTest and Microsoft.Testing.Platform projects using MSTest, xUnit, NUnit, bUnit, and TUnit. F# and Visual Basic source discovery are included.

JUnit and Cobertura reports can be imported from the command palette. Imported test results remain report-only until an adapter with the same id is registered.

Commands

Command Use
Open Open the utility dock and discover the workspace.
Run Selected Run the test selected in the tree.
Run Nearest Run the test nearest the source cursor.
Run Current File Run tests declared by the active file.
Rerun Failed Run the current failing set.
Toggle Coverage Collect or hide source coverage.
Show Output Read and copy complete runner output.
Stop Kill the active discovery, test, or coverage process.
Import Report Load JUnit or Cobertura XML.

Dock keys

The dock uses r for the selected test, a for all tests, n for nearest, f for the filter, o for output, c for coverage, w for watch, ] for the next failure, x to stop, and q to close. Palette commands can be assigned global shortcuts in Fresh's keybinding editor.

Settings and state

Fresh's Settings UI exposes run on save, coverage on save, adapter selection, nextest preference, .NET no-build and no-restore switches, .NET verbosity, coverage thresholds, terminal runs, report location, auto-open on failure, and dock width. Reports default to the active authority's temporary directory, outside the workspace.

The selected test, expansion state, filter, sort, failed-only view, watch mode, and open state are kept with the Fresh session. Coverage for an edited file is cleared immediately because the old line data is no longer trustworthy.

Status bar

The status token is fresh-test-observatory:test-summary. Add it to the left or right section under Settings, Status Bar. Fresh 0.4.10 does not expose click handlers for plugin status tokens, so opening the dock remains a palette or keybinding action.

Workspace trust

Source discovery works in restricted workspaces. Test commands, builds, and coverage run only when Fresh reports the exact trusted state.
